# Mahir Asaf Khan - Personal Portfolio

A professional, modern dark-mode personal portfolio website built with React, TypeScript, and Tailwind CSS.

## Features
- **Responsive Design**: Looks great on desktop, tablet, and mobile.
- **Modern Aesthetic**: Sleek dark mode with vibrant gradients.
- **Smooth Navigation**: Single-page layout with animated transitions.
- **Integrated Sections**: About, Education, Skills, Projects, and Experience.

## Tech Stack
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **Framer Motion** (Animations)
- **Lucide React** (Icons)
- **Vite** (Build Tool)

## Deployment to GitHub Pages

This project is configured to be deployed automatically to GitHub Pages using GitHub Actions.

### Steps to enable:
1. Push this code to your GitHub repository (ensure the main branch is named `main`).
2. On GitHub, navigate to your repository **Settings**.
3. Go to **Pages** in the left sidebar.
4. Under **Build and deployment > Source**, select **GitHub Actions**.
5. Once you push to the `main` branch, the deployment will start automatically. You can monitor the progress in the **Actions** tab.

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
